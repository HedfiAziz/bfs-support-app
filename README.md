# BFS Solutions — Plateforme Support & Assistance AMS

Application web de gestion des tickets d'assistance pour le périmètre **Sage XRT & Cash Management**.

## 🛠️ Technologies utilisées
* **Backend :** Python (Flask), SQLAlchemy, SQLite
* **Frontend :** HTML5, CSS3 (Design System Corporate), JavaScript (ES6)

## 🚀 Fonctionnalités
* Formulaire client avec attribution dynamique de la sévérité SLA.
* Console d'administration interactive (suivi des incidents, métriques KPI, filtres par statut).
* Modal de consultation détaillée et actions directes (téléphone / email).
* Export des données au format CSV.

## 💻 Installation locale
1. Cloner le projet : `git clone <URL_DU_DEPOT>`
2. Installez les dépendances : `pip install -r requirements.txt`
3. Lancer l'application : `python app.py`
